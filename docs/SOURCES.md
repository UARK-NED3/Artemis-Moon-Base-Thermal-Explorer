# Source and data boundaries

## Local source documents

The user-downloaded PDFs in `dataset/` are intentionally ignored by git and preserved as read-only local reference material:

- NASA, *Human Landing System Lunar Thermal Analysis Guidebook*, HLS-UG-001 (2021).
- NASA, *Moon Base User's Guide* (local downloaded edition).
- NASA, *Passive Thermal Control Engineering Guidebook*, Revision 4 (2023).

## Public source links

- [LRO Diviner Derived Data Bundle](https://pds.nasa.gov/ds-view/pds/viewBundle.jsp?identifier=urn%3Anasa%3Apds%3Alro_diviner_derived1&version=5.0)
- [LRO LOLA Gridded Data Products](https://pds.nasa.gov/ds-view/pds/viewDataset.jsp?dsid=LRO-L-LOLA-4-GDR-V1.0)
- [Apollo 15 Heat Flow Experiment Data Bundle](https://pds.nasa.gov/ds-view/pds/viewBundle.jsp?identifier=urn%3Anasa%3Apds%3Aa15hfe_thermal_conductivity&version=1.0)

No NASA or PDS dataset is included in v0.1. Before a data adapter is added, record the product/collection identifier, retrieval date, license or reuse statement, units, coordinate system, time basis, processing level, and checksum.
